# GB885-Discussion
Repository using assignment 2 for the discussion

Cookie store has a daily menu of five cookies that changes daily. Cookies are baked once in the morning and are not replaced throughout the day. Only one type of cookie is allowed per customer order.

The code starts with a dictionary of the Monday menu, including stock and price for each item

Using the datetime function to automatically reference the current date

Interface: Accepts input statements for what cookie and how much, then error messages for if that item is too limited, out of stock, if the customer would like to change their order. For complete orders, it returns the order total
